# Screenshots Directory

This directory contains visual captures of VirtualBox hardware setup, pfSense OS installation, interface assignment, and diagnostic screens:

1. `01-vbox-network-adapters.png` - VirtualBox VM network adapter configuration panel.
2. `02-pfsense-install-welcome.png` - pfSense ISO boot welcome & installer selection menu screen.
3. `03-pfsense-install-extracting.png` - pfSense installer extracting system distribution files (`base.txz`).
4. `04-pfsense-install-complete.png` - pfSense installer completion and system reboot prompt.
5. `05-pfsense-console-booting.png` - pfSense console startup sequence and service initializations.
6. `06-pfsense-console-menu-initial.png` - pfSense console options menu upon initial boot.
7. `07-pfsense-interface-assignment.png` - Console interface assignment wizard mapping `em0`–`em5`.
8. `08-pfsense-console-menu-assigned.png` - Console options menu after mapping WAN, LAN, and OPT1–OPT4.
9. `09-troubleshooting-kernel-panic.png` - VirtualBox VM boot failure with Linux kernel panic diagnostic screen.
