Security Rule Matrix

Top-to-bottom, first-match-wins rule processing with default-deny posture across all interfaces.

🛡
Management (em1)
10.0.0.0/24
  • PASS Admin hosts → WebGUI & SSH
  • PASS DNS queries → pfSense resolver
  • PASS Outbound Internet access
  • PASS Full access to all internal subnets
  • DENY Default deny catch-all

10.10.10.0/24

  • PASS Security logs → Wazuh/SIEM
  • PASS Attack traffic → AD targets
  • DENY Block access to Management net
  • PASS Outbound Internet for updates

10.20.20.0/24
  • PASS DNS → local resolver
  • PASS AD audit logs → SIEM
  • DENY Block access to Management net
  • PASS Internet for WSUS / NTP

10.30.30.0/24
  • PASS DNS → pfSense
  • PASS SIEM scanners → internal hosts
  • PASS Internet for threat intel feeds

10.40.40.0/24
  • PASS DNS (intercepted / sinkholed)
  • DENY ALL inter-VLAN access blocked

Implementation Roadmap

Structured Learning Path

Follow this five-phase roadmap to build a deep understanding and successfully deploy the entire lab.

Phase 1 — Understand
Conceptual Architecture & Design
Study the design rationale, network topology diagrams, and master IP allocation plan. Understand why pfSense acts as the central gateway with 6 NICs emulating enterprise hardware.
Phase 2 — Provision
Hypervisor & Base OS Setup
Create VirtualBox VMs with proper resource allocation. Install pfSense CE, assign console interfaces (em0–em5), and deploy the Ubuntu management workstation.
Phase 2.5 — Configure
Post-Wizard Configuration Protocol
Rename interfaces, assign static gateway IPs, enable DHCP pools, verify internet egress, create network aliases, and take a baseline VirtualBox snapshot.
Phase 3 — Enforce
WebGUI Services & Policy Enforcement
Configure DHCP scopes, implement stateful default-deny firewall rules, set up outbound NAT & port forwarding, and harden Unbound DNS resolver with AD domain overrides.
Phase 4 — Verify
Validation & Diagnostics
Execute cross-subnet ping tests, Nmap scans, and WebGUI access checks. Use the troubleshooting guide for DHCP failures, DNS loops, and adapter mismatches.
