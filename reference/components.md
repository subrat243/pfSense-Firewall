# Component and Download Reference

Use the official project distribution channels and check each product's current
system requirements before deployment. Evaluation products remain subject to their
license terms.

| Component | Role | Official source |
| :--- | :--- | :--- |
| VirtualBox and Extension Pack | Hypervisor | [virtualbox.org](https://www.virtualbox.org/) |
| pfSense CE | Firewall/router | [pfSense download](https://www.pfsense.org/download/) |
| Ubuntu Desktop | Management workstation | [ubuntu.com](https://ubuntu.com/download/desktop) |
| Metasploitable 2 | Vulnerable Linux target | [SourceForge](https://sourceforge.net/projects/metasploitable/) |
| Metasploitable 3 | Vulnerable Windows/Linux targets | [rapid7/metasploitable3](https://github.com/rapid7/metasploitable3) |
| OWASP Juice Shop | Web application training target | [Docker Hub](https://hub.docker.com/r/bkimminich/juice-shop) |
| DVWA | Web application training target | [digininja/DVWA](https://github.com/digininja/DVWA) |
| SafeLine | Web application firewall | [SafeLine](https://waf.chaitin.com/) |
| Windows Server and Windows Enterprise evaluation media | Active Directory lab | [Microsoft Evaluation Center](https://www.microsoft.com/evalcenter/) |
| Sysmon and Sysinternals | Endpoint telemetry | [Microsoft Sysinternals](https://learn.microsoft.com/sysinternals/) |
| BloodHound | Active Directory analysis | [BloodHound](https://github.com/SpecterOps/BloodHound) |
| Impacket | Network protocol and security testing tools | [Fortra Impacket](https://github.com/fortra/impacket) |
| Wazuh | SIEM and endpoint monitoring | [wazuh.com](https://wazuh.com/) |
| Security Onion | Security monitoring platform | [securityonion.net](https://securityonion.net/) |
| FLARE-VM | Windows analysis workstation | [mandiant/flare-vm](https://github.com/mandiant/flare-vm) |
| REMnux | Linux analysis workstation | [remnux.org](https://remnux.org/) |
| INetSim | Simulated network services | [inetsim.org](https://www.inetsim.org/) |

See the relevant [segment guides](../segments/README.md) for placement and
configuration requirements. Keep vulnerable targets and analysis systems isolated
on their assigned internal VirtualBox networks.
